# RajanShop — InAmigos Foundation Task 3

A responsive demo e-commerce storefront built with plain HTML, CSS, and JavaScript.

## Website sections
- Home / hero
- Shop by category
- Product listing with search, category filters, and price sorting
- Demo shopping cart with quantity controls and subtotal
- About RajanShop
- Newsletter demo form
- Contact section and footer

## Run locally
1. Download or extract this project folder.
2. Open `index.html` in a modern browser.
3. For a local development server, open a terminal in this folder and run:
   - `python -m http.server 8000`
4. Visit `http://localhost:8000`.

No build tools or external libraries are required.

## Publish for a live link
### GitHub Pages (free static hosting)
1. Sign in to GitHub and create a new public repository, for example `rajan-shop-task3`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to finish publishing. Copy the live URL shown in the Pages settings.
7. Open the URL on both mobile and desktop to test it.

## Important demo notice
This is a student project prototype. Product names, prices, ratings, cart, and newsletter are illustrative. The cart does not create orders, the newsletter does not store email addresses, and no real payments are processed. Do not collect real customer data without adding appropriate backend, privacy, security, and payment functionality.
